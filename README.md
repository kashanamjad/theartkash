# theartkash.com

One-page site for The Artkash, a film and photo studio in Dubai. Plain HTML, CSS and JS, served by GitHub Pages.

- **Edit content** (headline, hero photos, services, films, photos, team, contact) at [app.pagescms.org](https://app.pagescms.org). Everything lives in `content/site.json`; uploads go to `assets/media`.
- **Films:** H.264 MP4, ideally under 20 MB each. Add a poster image (a still, same shape) and set the shape to horizontal or vertical.
- **Team photos:** PNG cut-outs with a transparent background.
- After changing `assets/css/site.css` or `assets/js/site.js`, bump the `?v=` number in `index.html` so browsers fetch the new file.
